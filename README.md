# EuroLoot Website

This took so long to make, and I am not even near finished.

Welcome to the official website repository for **EuroLoot**, an upcoming European gaming retailer and platform built around making gaming more accessible, convenient, and connected across Europe.

## About EuroLoot

EuroLoot is a project founded on the idea of creating a trusted destination for gamers across the European Union. The long-term vision is to bring games, gaming hardware, consoles, accessories, collectibles, and great deals together in one place.

The website is a work in progress, and there is still a considerable amount to build before EuroLoot is ready for its official launch.

## Current Status

**Under development.**

EuroLoot is not yet officially launched. The website is being developed and improved as work continues on the platform, its infrastructure, and its overall experience.

Features, designs, and other aspects of the website may change significantly throughout development.

## Vision

The goal is to build more than just another gaming store. EuroLoot aims to develop into a reliable gaming destination for customers across the European Union, with an emphasis on accessibility, trust, usability, and a straightforward shopping experience.

The broader vision includes:

* **Games:** Digital and physical gaming titles.
* **Hardware:** Consoles, gaming accessories, and other hardware.
* **Collectibles:** Products for gaming enthusiasts and collectors.
* **Deals:** Competitive offers and opportunities to discover new products.
* **Marketplace:** Potential future expansion into additional marketplace services.
* **Community:** Opportunities to bring European gamers closer together.

These are long-term ambitions and should not be interpreted as a list of features currently available.

## Technology

The website is being developed using modern web technologies and supporting services. Its implementation, architecture, and integrations may evolve as development progresses.

This repository contains the website's source code and related project files.

## Development

EuroLoot is an independently founded project currently being developed by its founder. Development is ongoing, and the project is not yet feature-complete.

There is a lot left to do, from refining the website itself to building the systems needed to support the wider EuroLoot platform.

The current implementation should therefore be considered a work in progress rather than a finished product.
